# 🎓 Undergraduate Engineering Electronics Lab Teaching Suite

An interactive Python toolkit for teaching **second-year electronics engineering**.
Covers RC circuits, filters, RLC resonance, op-amps, and BJT biasing — with
live simulations, structured lessons, worked examples, and an auto-graded quiz
in a single Tkinter GUI.

Built as a teaching portfolio project: it demonstrates curriculum design,
Python engineering, and classroom-ready demos.

By Mussawir Hosany, mussa.hosany@gmail.com 
PCEP, PCAP

---

## ✨ Features

| Module | What it teaches |
|--------|-----------------|
| **RC Circuit** | Time constant τ, charging/discharging, cutoff frequency |
| **Filters** | First-order LP/HP Bode plots, -3 dB, phase response |
| **RLC** | Resonance f₀, damping factor ζ, Q-factor, under/over/critical damping |
| **Op-Amp** | Inverting, non-inverting, voltage follower gains |
| **BJT** | Voltage-divider bias, Q-point calculation |
| **Lessons** | 5 structured lessons with theory + demo + exercise + answer |
| **Quiz** | Randomized MCQs with explanations and live score |
